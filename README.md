🧪 Sistema de Exames Laboratoriais em Java

Aplicação desenvolvida em Java para gerenciamento e análise de exames laboratoriais, permitindo o cadastro, validação e organização de informações clínicas de forma simples e eficiente.

O projeto foi desenvolvido com foco em aprendizado de lógica de programação, estruturação de dados e boas práticas em Java.

📌 Objetivo do Projeto

Este sistema tem como objetivo auxiliar no controle e manipulação de exames laboratoriais, simulando um ambiente básico de gerenciamento clínico.

O projeto aborda conceitos importantes como:

Estruturas condicionais
Laços de repetição
Entrada e saída de dados
Organização lógica
Programação orientada a objetos
Manipulação de informações em Java

▶️ Como Executar o Projeto
1️⃣ Clone o repositório
git clone https://github.com/SHERLON20/exames-de-laboratorios.git
2️⃣ Acesse a pasta do projeto
cd exames-de-laboratorios
3️⃣ Compile o arquivo Java
javac Exames.java
4️⃣ Execute o projeto
java Exames
